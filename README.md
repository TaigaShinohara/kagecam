# KageCam

怖い影の画像が作れるカメラ。DOBU LAB 架空プロダクト連載 記事#006 の実アプリ化。
v0.1 の実機フィードバック「影だけ抜くといい感じに怖くなる」を受けて、v0.2 で
「怖い画像が作れるアプリ」へ再構築した（経緯は docs/ART_DIRECTION.md の改定履歴）。

- 撮る／写真を選ぶ → 影だけ抽出 → 「怖くする」編集 → 日付つきで棚に並べる
- 怖くする：プリセット3種（ゆうれい／あか影／影絵）＋調整4本（影の残り具合／残像／引き伸ばし／ノイズ）
- v0.3：保存時に元画像＋パラメータも一緒にしまい、後から「怖くし直す」で再編集できる。詳細から共有シートで外へ送れる（審査R-2と共有候補の解消。docs/CONCEPT_REVIEW_v0.2.md）
- v0.4：操作UIも「夜」のダーク基調へ（アート方針2.1）。怖さは色・明暗・余白だけで作り、装飾やフォントでは作らない
- 影抽出は明暗の切り分け＋大津法。端末内保存のみ。アカウント・サーバー・課金なし
- 将来候補：影絵アートづくり（重ね＋色）、場所の記録、AIセグメンテーション

## ビルド

このVMでは `./build.sh :app:assembleDebug`（Gradle 8.9＋ローカルミラー経由。理由は build.sh と AGENTS.md 参照）。
通常の開発機では settings.gradle.kts のリポジトリを google() / mavenCentral() / gradlePluginPortal() に戻して `./gradlew` でビルドできる。

- v0.5：ホラー体験の軸E（音）を採用。編集画面で「いまの場所の音」を6秒録音して作品に同封でき、詳細画面で「その時の音を聴く」から再生できる（自動再生なし）。マイク許可が必要で、許可しない場合は音なしで通常どおり使える。共有は画像のみ（音は同封されない）

- v0.6：UX審査（CONCEPT_REVIEW_v0.5）の必須＋推奨を解消。コンセプトをアート方針2.3 §0に一本化（生成しない。実在した影を、剥がす。／実在性・決定性・端末内完結）。音は「仕上げの時に添える音」と定義し文言を「添えた音を聴く」に統一。棚カードに音印、再編集で既存音の表示と「音を外す」、共有は画像のみの注記、削除色の統一、録音カウントダウン、再生音量0.75、編集画面に「元の写真と見比べる」を追加。残る必須は S-3＝実機での怖さ＋音の体験確認のみ
- v0.6.1：不具合の総点検と修正。台帳（index.json）を原子的に書くよう変更し、壊れた場合はバックアップ→実ファイルからの再構築で復旧（作品を失わない）。作品IDの衝突回避。真っ平な画像での大津法フォールバック。録音の開始/停止失敗でレコーダーが残らない・壊れた音を同封しない。再生エラー時の状態復帰。保存の二度押し・録音中の保存を防止。棚と詳細の画像読み込みを非同期化。EXIF転置の向き補正。画面回転・再生成でも編集中の写真と調整が消えないよう復元対応。端末内完結に反する自動バックアップを無効化

- v0.7：「撮る」で撮影すると、編集画面に入った直後にその場の音を自動で6秒録音して同封するようになった（方針2.4）。カメラアプリが前面の間は録音できないため開始は復帰直後。途中で止める・外すことも従来どおり可能。「写真を選ぶ」と再編集では自動録音しない。許可が無い場合は一度だけ尋ね、断られたら音なしで使える
